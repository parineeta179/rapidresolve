# RapidResolve – Government Scheme Finder 🇮🇳

RapidResolve is a web-based application that helps users easily explore and find relevant **Indian government schemes** based on their needs.  
The project aims to simplify access to welfare schemes by presenting them in a clean and user-friendly way.

---
## 🚀 Features
- 📋 View available government schemes
- 🔍 Simple and clean user interface
- ⚡ Fast response using a lightweight backend
- 🗂️ JSON-based data handling
- 🖥️ Beginner-friendly project structure
---
## 🛠️ Tech Stack
**Frontend**
- HTML
- CSS
- JavaScript

**Backend**
- Node.js
- Express.js

**Database**
- JSON (`db.json`)
